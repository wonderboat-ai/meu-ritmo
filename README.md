# Meu ritmo

Um questionário sobre o seu cotidiano. A aplicação reúne 50 situações das últimas quatro semanas e apresenta um resumo local das respostas.

[Abrir o Meu ritmo](https://wonderboat-ai.github.io/meu-ritmo/)

O código está em `public/`. Use `npm start` para servir a aplicação e `npm test` para verificar o banco e o motor. Os comandos `npm run test:browser` e `npm run test:a11y` executam as suítes de interface após instalar o Playwright e o Chromium. `npm run pages` recria o `index.html` de publicação.
